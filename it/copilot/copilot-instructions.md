# Memoria persistente — GitHub Copilot

Prima di iniziare qualsiasi lavoro su questo repository, leggi `repodoc/memory-protocol.md` e segui il protocollo di memoria persistente che descrive per l'intera sessione.

Applica la modalità di scrittura CLI o chat definita nella sezione GitHub del protocollo.

Rileggilo se il file risulta cambiato rispetto all'ultima sessione: descrive lo stato corrente del protocollo, non va assunto da memoria.
